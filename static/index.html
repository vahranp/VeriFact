Fact Knowledge Layer

Upload a PDF, extract facts, see what corroborates / contradicts / reconciles across documents.
What happens on upload: the PDF is split into pages, each page is sent to an LLM to extract facts grounded in an exact quote from that page, each fact is embedded locally, and then compared against every existing fact in the knowledge layer (via embedding similarity + LLM judgement) to find corroborations, contradictions, and context-reconciled differences. Processing runs in the background — switch to the Documents tab to watch status.
