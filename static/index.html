How it works
1
Extract, page by page
Each page is sent to a local LLM, which decides what's checkable and grounds every claim in an exact quote.
2
Verify grounding
Every quote is checked in code against the source page — not just trusted from the model.
3
Shortlist candidates
Local embeddings cheaply find which facts might relate to each other, before spending an LLM call.
4
Judge the relationship
Shortlisted pairs get one LLM call each: corroborates, contradicts, reconciled, or unrelated — with reasoning.
